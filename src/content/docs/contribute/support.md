- **Questions and ideas:** [Discussions](https://github.com/orgs/zacesshq/discussions), with [Q&A](https://github.com/orgs/zacesshq/discussions/categories/q-a) for help and [Ideas](https://github.com/orgs/zacesshq/discussions/categories/ideas) for suggestions
- **Bugs and feedback:** [Discussions](https://github.com/orgs/zacesshq/discussions) or [contact@zacess.com](mailto:contact@zacess.com) until issues open on [zacesshq/zacess](https://github.com/zacesshq/zacess) with the first release
- **Accessibility barriers:** see [ACCESSIBILITY.md](/docs/contribute/accessibility/). An accessibility problem is a bug
- **Using AI in a contribution:** read the [AI policy](https://github.com/zacesshq/.github/blob/main/AI_POLICY.md) first
- **Privacy and your data:** [PRIVACY.md](/docs/contribute/privacy/) says what the apps store and what the website records. Questions go to [contact@zacess.com](mailto:contact@zacess.com)
- **Security vulnerabilities:** follow [SECURITY.md](/docs/contribute/security/), never a public post
- **General enquiries:** [contact@zacess.com](mailto:contact@zacess.com)

> **Note**
>
> Zacess is pre-release, so there is nothing to install yet. News about the first release is posted in [Announcements](https://github.com/orgs/zacesshq/discussions/categories/announcements) and on [zacess.com](https://zacess.com).
